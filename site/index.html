EZRA documentation¶

Easy Zero-setup Routing Assistant for local and HPC LLMs: download curated free/open models, pick ones that fit your machine, scaffold personal agents, and stage jobs on SLURM.

This site is built with Sphinx using reStructuredText (.rst) and MyST Markdown (.md). You can still read the same guides as plain Markdown on GitHub under docs/.

Tip

Unsure which model to download? Run ezra models recommend chemistry (or another keyword). See Models.
