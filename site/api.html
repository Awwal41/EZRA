Open a conversation session bound to an agent and/or gallery model.

Parameters:

  • agent (str | None) – Name under agents/<name>/ (loads prompt + preferred models).

  • model (str | None) – Gallery alias override (or sole binding when agent is omitted).

  • backend (ChatBackend | None) – Completion backend. If omitted, builds a local runtime via ezra.inference.create_backend() (requires .[local] / .[mlx]). Pass StubBackend() in tests.

  • root (Path | None) – Repo root for agent lookup (tests).

  • config (EzraConfig | None) – Loaded ezra.yaml (router defaults + optional install probe).

  • available_models (Collection[str] | None) – If set, preferred/fallback resolution prefers these names. If omitted, probes installed models when possible.

  • system_prompt (str | None) – Override system text (skips reading prompt.md when set).

Raises:

  • ValueError – neither agent nor model given, or no model can be resolved.

  • FileNotFoundError – agent profile missing.

  • RuntimeError – local backend unavailable when backend is omitted.

Document parsing¶

Document parsing for LLM ingestion (MegaParse + lightweight basic backend).

Typical usage:

from ezra.parse import parse_file

doc = parse_file("paper.pdf")
session.send(doc.as_chat_context() + "\n\nSummarize the methods.")

Install MegaParse runtime deps with pip install -e ".[parse]" (Python ≥ 3.11). Vendored sources live under third_party/MegaParse/ (Apache-2.0).

Peekaboo (macOS)¶

Peekaboo integration — macOS screen capture / UI automation for EZRA agents.

Upstream is a full in-tree snapshot at third_party/Peekaboo/ ([openclaw/Peekaboo](https://github.com/openclaw/Peekaboo), MIT).

Peekaboo is macOS-only. On other platforms helpers report unavailable and CLI wrappers raise a clear error. Prefer this package over calling the vendor tree directly so agents, doctor, and MCP config share one resolution path.

Typical usage:

from ezra.peekaboo import peekaboo_available, resolve_cli, capture_screen

if peekaboo_available():
    path = capture_screen()  # → ~/.ezra/captures/...

OpenClaw (Gateway)¶

OpenClaw integration — personal AI gateway for EZRA agents (optional).

Upstream sources are a full in-tree snapshot at third_party/OpenClaw/ ([openclaw/openclaw](https://github.com/openclaw/openclaw), MIT) — not a submodule — so EZRA keeps the code even if upstream goes away. See third_party/OpenClaw/UPSTREAM.txt.

This package is a thin, safe facade:

  • Locates the vendored tree / CLI

  • Reports availability for ezra doctor

  • Does not auto-run onboard, install daemons, or expose the Gateway

Prefer importing from here instead of the TypeScript tree under third_party/OpenClaw/.

Typical usage:

from ezra.openclaw import openclaw_available, openclaw_root, resolve_cli

if openclaw_available():
    print(openclaw_root(), resolve_cli())
