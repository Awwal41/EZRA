# EZRA IDE extensions

Sideload-only. Do **not** publish these to a marketplace.

| Path | Editor |
|------|--------|
| [`vscode/`](vscode/) | VS Code and Cursor (same VSIX) |

```bash
ezra ide install                 # every editor found
ezra ide install --ide code      # Visual Studio Code
ezra ide install --ide cursor    # Cursor
```

In VS Code, chat is **EZRA: Open Grid** (sidebar), not Copilot Chat. Guide:
[docs/ide.md](../docs/ide.md) · extension README: [vscode/README.md](vscode/README.md).
